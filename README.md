Calculadora 1.0

Projeto de calculadora em Java executado no terminal.

Funcionalidades

- Soma, subtração, multiplicação e divisão;
- Suporte a números decimais;
- Validação de operador inválido;
- Proteção contra divisão por zero;
- Resultado exibido com duas casas decimais;
- Repetição de cálculos sem reiniciar o programa;
- Validação da resposta 'S/N' ao continuar.

É necessário Java 15 ou superior, pois o programa utiliza blocos de texto.

 Opções do menu

| Opção | Operação |
|-------|----------|
| 1 | Soma (+) |
| 2 | Subtração (-) |
| 3 | Multiplicação (*) |
| 4 | Divisão (/) |

Exemplos de validação

- '10 / 0' mostra uma mensagem de erro e não exibe resultado;
- um operador fora de '1' a 4' mostra o menu válido;
- respostas diferentes de 'S' ou 'N' são pedidas novamente.
